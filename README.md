# BookTrail

**A Library Book Lending Management Application**

BookTrail is a web application developed as part of the Advanced Client-Side Development coursework. The project focuses on building a simple and user-friendly interface for managing library book lending activities.

The application is being developed using React and TypeScript, with an emphasis on component-based development, reusable UI elements, client-side state management, and responsive design.

## Technology Stack

The initial project setup uses the following technologies:

- **[React](https://react.dev/learn)**: Building the user interface.
- **[TypeScript](https://www.typescriptlang.org/docs/)**: Adding static typing.
- **[Vite](https://vite.dev/guide/)**: Providing development and build tooling.
- **[ESLint](https://eslint.org/docs/latest/)**: Maintaining code quality.

Additional libraries and tools will be introduced as the project develops.

## Getting Started

### Prerequisites

Make sure the following tools are installed:

- [Node.js](https://nodejs.org/)
- [npm](https://docs.npmjs.com/) (included with Node.js)
- [Git](https://git-scm.com/docs)

### Installation

Clone the repository:

```bash
git clone https://github.com/dilruk25/book-trail.git
```

Navigate to the project directory:

```bash
cd book-trail
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will provide a local URL, usually `http://localhost:5173/`, where the application can be accessed through a browser.
